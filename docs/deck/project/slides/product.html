This is the burning calendar the challenge asks for. Each row is a year, each column a month, all in the same unit, so 2004 and 2024 can be compared directly. You pick an area by drawing it, typing coordinates or dropping a file. The first thing you read is the answer: how this month compares with its normal. Everything is computed in the browser by a Rust kernel compiled to WebAssembly, reading small static tiles, so there is no query server to run. And you can download the hotspots for your search as a CSV.
