2 / 7

Satellites have counted active fires since 2000, but on two generations of sensors. VIIRS has finer pixels, so it reports about four times as many hotspots as MODIS for the same fires, and thirteen times now that three VIIRS satellites report. If you simply append one record to the other, every area on Earth appears to start burning far more in 2012. And the hand-over is happening now: Suomi NPP stopped delivering data on 2 November, and MODIS is close to retirement. Anyone comparing this fire season with the last twenty needs a single consistent record.
