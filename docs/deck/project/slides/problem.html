Satellites have counted active fires since 2000, on two generations of sensors. VIIRS has finer pixels than MODIS, so for the same fires it reports about four times as many hotspots. Each time another VIIRS satellite is launched the raw count steps up again: seven to eight times with two, twelve to thirteen with three. So if you append one record to the other, every place on Earth appears to burn far more from 2012. And the hand-over is happening now. Suomi NPP stopped delivering data on 2 November, and MODIS is close to retirement. Anyone comparing this fire season with the last twenty needs one consistent record.
